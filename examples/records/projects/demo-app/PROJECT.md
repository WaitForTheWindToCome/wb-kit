# 内部工具（示例项目）

> 这是示例数据，用于演示 wb-kit 的结构。场景：给内部运营工具加上 SSO 登录。

## 目标与成功判据
1. 运营同事用公司账号登录，不需要再发本地账号；
2. 登录成功率 ≥ 99.5%，P95 登录耗时 < 1.5s；
3. 老账号可平滑迁移，迁移期不中断使用。

## 范围与非目标
- 范围：OIDC 接入、账号映射、灰度切换。
- 非目标：自建 IdP、细粒度权限体系（下一期再说）。

## 当前里程碑
M1 选型决策（完成） → M2 打通登录链路 → M3 灰度迁移 → M4 全量与下线本地账号。

## 相关方
运营负责人（业务方）、IT（IdP 管理员）、研发两人。
